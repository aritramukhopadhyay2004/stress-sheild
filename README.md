# Stress-Shield - AI-Powered Stress Monitoring System

Real-time health monitoring system that detects stress levels and provides personalized interventions.

## Tech Stack

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express + Socket.io
- **ML Service**: FastAPI + scikit-learn
- **Database**: Supabase (PostgreSQL)
- **Hosting**: Vercel (Frontend) + Render (Backend/ML)

## Local Development

### Prerequisites

- Node.js 18+
- Python 3.10+
- Supabase account
